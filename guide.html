PROJECT GUIDE

How emergency dispatch works

This demonstration turns a caller's report into a structured emergency, selects an ambulance using shortest-path calculations, and shares the route with the driver dashboard.

01

Report the emergency

The Patient / User profile captures the caller's description and a supported location or landmark.

02

Understand the report

The browser-based AI classifies the emergency and extracts details. If the model is unavailable, local rule-based extraction is used.

03

Select and notify an ambulance

The dispatcher compares available ambulances by their shortest route to the emergency, then sends the request to the Ambulance profile.

04

Track progress and destination

The driver can accept the request, travel to the emergency, continue to the selected hospital, and report status updates to the caller dashboard.

⌁
ROUTE OPTIMIZATION

Why Dijkstra's algorithm?

Dijkstra's algorithm finds the lowest-cost route through a graph when every road segment has a non-negative weight.

What the graph represents

Locations are graph nodes, and connected roads are edges. Each demo edge has a travel-time weight in minutes.

How dispatch uses it

It calculates a shortest route from each available ambulance to the incident. The ambulance with the smallest route total is selected. The same method finds the shortest route from the incident to a demo hospital.

What you see

The chosen paths and estimated times appear in the dispatch and driver views. During the driver demo, the vehicle marker moves along the calculated path.

Prototype note: Locations, road connections, travel-time weights, and vehicle movement are simulated. These estimates are not live traffic, GPS navigation, or a real emergency service.
